**普通长流协议处理 p75 1067.47→260.60 ms，4.10×；短流 23.32→18.13 ms，1.29×。** 这是公开消息投影、协议编码及客户端解码/状态应用的 CPU 热路径，不是整个产品或模型推理提速。实际浏览器短流首正文 p75 78.2→75.3 ms，未达三倍，且接近帧调度噪声。没有改动供应商/模型、回答质量、可见等待或输出内容。

## 方法 → 证据 → 实现 → 短期验证

已读取 [claude.ai 性能文章](https://claude.dev/blog/how-we-made-claude-ai-faster/)（2026-09-23）与 [源码管理文章](https://www.anthropic.com/engineering/redesigning-source-control)（2026-10-13，15 日更新）。前者启发本轮的用户旅程分段、实验室计数、逐步修复及回归闭环；后者“增量工作、按需派生”的原则在此仅作跨领域推断，不引入 Scion 或新的基础设施。

| 方法 | 本项目证据 | 实现与验证 |
| --- | --- | --- |
| 比较可数的重复工作并关联耗时 | 原长流 14,837 次 stringify，累计 245,713,137 字符；每个对象层再次串行化整棵子树 | 结构比较、每个响应保留一个已规范化快照。最终降为 1,206 次 / 35,455,027 字符（减少 85.57%）；逐帧语义与整条 wire SHA-256 相同 |
| 只构建实际需要的输出 | 402 个原生事件产生 804 次快照；apply 返回值被丢弃 | 分离 advance 与快照物化，完成审批/终态刷新后仅构建一次；仍逐事件校验、保留缺帧检测及取消。快照 804→402 |
| 剖析剩余热点继续迭代 | 两步后 CPU 采样约 24% self time 在可视化前缀/Markdown code-range 扫描 | 仅在文本不含 ASCII 冒号和 Unicode 指令起始符时跳过扫描；其余路径继续原固定解析器。修改前先覆盖所有部分前缀、转义、代码区、完成/未完成/非法引用；上游 223 文件校验通过 |
| 输出护栏与发布后验证 | 协议/内容不能为了指标改变 | 基线和候选共用黄金护栏；桌面/手机像素差均 0。唯一集成人发布后补生产数据；本分支没有部署 |

两个步骤的有效中间实验见 `two-step-paired.json`（长流 p75 1046→369 ms，2.83×）。第三步独立提交后最终重新配对；不同轮次数值不能直接相减当作单步精确贡献。`evidence/cpu-profile-summary.json` 明确标识第三步之前的提交。更早的 `*-smoke.json`、`preinstalled-paired.json` 使用预装旧依赖，仅为被排除的探索记录。

## 其他排查与边界

- 发现本地代理把 WebSocket 发给 control Worker 导致 EPIPE/重复取票，已修正**测试启动参数**并重新跑完产品基线；未改变产品鉴权。正确配置下取票一次。7/10 会话样本仍有两次 `/runs` 查询，可能来自初始发现/历史载入；目前没有证明其影响关键路径或可安全省略，未加入缓存。
- 连接池已有 SQL/acquire/wait 指标；未观察或证明本范围连接池是瓶颈，不增大池或改维护循环，不重复 #153/#196/#197。没有跨用户缓存，也没有缓存私密数据。
- 普通网页构建记录约 30.54s、15,137 modules；渲染 fixture 约 26.84s，已有大 chunk/`::highlight` 警告。未测得可归因的构建改进，不修改 CI、打包拓扑或日志安全策略。CI 任务由另一分支负责。
- 最终普通文本 fast path 对包含候选指令起始字符的回复保持原解析器路径；4.10×不能外推到这些内容。将来升级固定解析器时需要同步检查标记契约。
