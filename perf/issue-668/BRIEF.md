# 案例库交互与视觉对齐

范围：案例首页、置顶卡片、详情正文/目录，以及案例页对侧栏的样式覆盖。
能用：首次进入出现真实夹具案例和可操作的分类；分类点击后的匹配卡片已完成绘制。骨架不计入。
目标：分类切换 p75 至少减少一半，置顶案例 DOM 与封面保持挂载；不新增筛选请求。
约束：采用提供 HTML 的尺寸与排版；系统绿色按钮、无侧栏短线；真实内容/组织权限/管理能力保留。
口径：基线 adf2570a 与候选各启一套 Vite，1440×900；同一夹具、固定 100ms API 延迟；交替至少 10 次。测点击事件至两次 rAF，记录请求数与置顶节点身份；数据仅代表本机实验室，不冒充线上网络或真实用户 p75。
发布：沿用本会话的合并与生产发布授权，最终候选回归和独立审查通过后合并，由既有 CI deploy 验证。
复现：CASE_PREVIEW_PORT 设置端口，node scripts/fixtures/cases-preview.mjs，浏览器打开 /cases?benchmark。
