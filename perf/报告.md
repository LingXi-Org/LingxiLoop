# 网站速度优化报告

2026-10-13。按 [huashu-flash](https://github.com/alchaincyf/huashu-flash) 执行，范围为用户指定的登录、进入工作区、打开聊天并输入。登录可编辑 p75 降低 **34.0%**，工作区/聊天可编辑 p75 降低 **21.3%**；未达到简报中 50% 的目标。改动尚未部署。

## 最终配对结果

桌面和手机的可见文字、输入框几何相同，四对截图像素差均为 0。登录 CLS 为 0；聊天原始 CLS 约 0.148，前后相同。聊天首屏实际压缩 JS 1,066,193 → 930,469 bytes（减少 12.7%），CSS 108,438 → 53,817 bytes（减少 50.4%）。拆包后请求数增加，不能把请求数减少当作本次收益。

没有改善的指标也保留：聊天累计长任务 p75 993 → 1167 ms，p95 1267 → 1485 ms；这不是 INP，不能据此宣称输入响应全面改善。首键完成时间虽下降，真实用户 INP 与较弱设备的主线程压力仍需后续验证。登录累计长任务 p75 则为 155 → 60 ms。

最终速度采样 40/40 通过；性能上限固定在 `bench/ratchet.json`，比这次候选 p75 留约 5% 波动余量，同时必须优于同轮基线。最终结果不含已撤回实验或受类型检查负载干扰的聊天样本。

## 保留的改动

- `App` 把工作区初始化放入认证后的独立模块，保留账户/租户切换时的重新挂载、邀请入口与授权顺序。下载工作区界面与已授权导航并行，组件仍等待导航准备完成才挂载。
- 独立 `ProductLogo`，保留 `Avatar` 的旧导出，避免登录和邀请页面为了静态 Logo 加载头像生成器及其依赖。
- 普通聊天不再提前下载交互教学渲染器；收到对应消息部件时加载，等待时保留经过校验的文字解释。
- 画布预览按需加载，普通聊天不再提前下载画布样式及字体声明。预览、完整画布和焦点返回仍通过真实浏览器检查。

未升级依赖，未修改数据库、服务端鉴权或消息协议。工作区原有未提交修改保留在基线与候选中。

## 测量口径

压缩生产构建；Windows / Chrome 154；1440×960；冷缓存、CPU 1×；Fast 4G 下行 4 Mbps、上行 3 Mbps、延迟 20 ms。所有页面请求使用同一限制。每个操作前后各 10 次，按 A/B 交替执行，nearest-rank 分位数。真实隔离的 PostgreSQL、Redis、WuKongIM、API 与 control Worker；同一课堂内 6 条持久化中英文、列表和代码历史。发送后刷新确认过历史；测试代理任务已通过正常 API 取消。

`ready` 是页面可编辑，并由真实键盘输入和发送按钮状态验证；聊天另要求历史消息出现。`input` 包含自动化定位、聚焦及键盘往返，不能称作 INP。工作区时间是在导航和会话列表出现时记录；这次深链接中它与聊天可编辑时间接近。

原始数据、截图和最终汇总保存在 [bench/accepted](bench/accepted/)。复测及机器检查见 [bench/README.md](bench/README.md)。初始空课堂数据见 [基线](基线.md)，只用于定位，不与最终带历史的数据混算。
