# 本轮验收与失败条件

在实现 CI 入口前固定以下检查：

- 不把 GitHub Secret 读回本机，不把 Sigillo 密钥写入文件或日志。
- 安装阶段只接收包读取 token；评估子进程只接收与冻结协议匹配的模型 key，不能继承生产数据库、SSH 或部署凭据。
- 缺少与冻结协议匹配的模型 key 时明确失败，不能把其他供应商的 key 发到 DeepSeek，也不能静默换模型。
- 只使用独立 PostgreSQL 的固定本地端口；生产版本不匹配时停止实测。
- 正式包的版本、来源与完整性必须匹配；本地源码构建的替身验证不能计作正式实测。
- 先完成 72 次替身采集，再执行 72 次真实采集；评分器拒绝缺行、错序或不同协议。
- HTTP 认证、额度错误或中断保留脱敏的已有样本；不生成伪造的完整指标。
- 工件只上传评估记录、指标、报告与无密钥的来源信息；不上传环境、npm 日志或数据库。

验证方式：运行既有完整替身采集入口；用伪凭据检查供应商匹配和子进程环境白名单；对工作流执行静态检查。真实结果另行记录，不能用这些检查替代。
