---
name: product-copy
description: Review or write LingxiLoop copy shown to users in the app, website, email, or notifications.
---

Review visible text across app screens, accessibility labels, dialogs, toasts, the website, and notifications. Keep wording only when it helps users decide, act, understand a result, or supports accessibility, consent, privacy, or safety.

Use direct, plain language. State the user outcome or next step. Remove implementation details, internal sync or permission narration, roadmap claims, demo or test text, redundant explanations, and empty motivational copy unless needed for a user decision or an accurate status.

Verify claims about visibility, access, persistence, and availability against product behavior. Never expose raw diagnostic details.
