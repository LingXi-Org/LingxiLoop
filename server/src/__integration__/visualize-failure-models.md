# Visualize server failure models (written before implementation)

- A forged path, traversal, symlink, oversized/non-fragment HTML or arbitrary asset name must not expose a host file. PostgreSQL is authoritative; executor files are a bounded export mirror.
- Tenant/project/session membership, teacher-room constraints and the acting human must be checked on every document, state, page, resource and follow-up operation, including after revocation.
- Only an authorized run can save an artifact; only a durable assistant message from its agent can admit a rendered page.
- A guessed page ID, wrong owner/token, closed/expired/replaced page or old source revision must fail before state, resources or side effects.
- Page capacity and state eviction must be serialized; state is a full snapshot, personal, bounded to 16 KiB and 100 entries. Private state never enters model context.
- Author scripts must not mint gestures. Only the trusted host obtains a 5-second one-use gesture after browser activation, and only for its bound live page. Stale confirmation cannot authorize a replacement page.
- Follow-up retries must not duplicate durable messages; changed payload with same key must conflict; an unknown dispatch outcome must reconcile, never automatically resend. Generic ingress/webhooks cannot forge an admitted follow-up.
- openExternal accepts only http/https and rejects credentials/control characters. Private tweak callbacks remain page-local and acquire no file/tool capability.
- Migration 0046 is additive and transactional; 0033 and existing OpenUI data remain intact. Active OpenUI endpoints disappear without changing questionnaire, shared ledger or signed webhook boundaries.
