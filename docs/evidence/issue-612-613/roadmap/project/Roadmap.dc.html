全线的根本线索
一代解决一代的代价，而不是一代推翻一代：词表统计记不住远距离依赖 → 循环网络能记但只能顺序算、长距离易衰减 → 注意力能一次看到全部但代价是 O(n²) 的成对交互 → 于是有了稀疏／局部注意力、长上下文工程与 KV 缓存管理。
