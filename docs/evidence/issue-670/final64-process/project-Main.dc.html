输入网址后的完整链路

从按下回车，到看见网页

一次网页打开，是一串环环相扣的接力：先把域名翻译成服务器的数字地址，再找到通往那台机器的路并建立连接， 把请求安全送到进程、等着应用生成 HTML，然后让浏览器边解析边按需索取样式、脚本、字体和图片，最后排版、绘制并合成出屏幕上的像素。 下面按发生顺序拆成七段，每段讲清「谁在做、怎么做、卡在哪里」。
