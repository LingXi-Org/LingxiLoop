第三步：重复很多次之后，它会变成什么样

离散时：它是一张明细表
0、1、2、3 这四个结果各有概率，中间的值（比如两个半正面）根本不存在。
量变多时：它慢慢变成曲线
如果掷的不是 3 枚，而是 30 枚、300 枚，正面次数可能取的值越来越密，柱子的轮廓逐渐接近一条钟形的连续曲线——这就是正态分布常出现的由来。
实际用时：查曲线也算得准
次数很多时，逐项求和很麻烦；用那条连续曲线代替，误差很小，计算却简单得多。这就是连续分布实用价值的一个来源。
