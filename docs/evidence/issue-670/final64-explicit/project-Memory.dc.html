第二块板 · 收益从哪来

省下的不是乘法，是显存搬运

朴素注意力的实际耗时往往不在算术上，而在把中间矩阵写进显存、再读回来。FlashAttention 的贡献是改变访问顺序与中间数据的生命周期：分块内完成一个输出块的全部计算，只把小块输入搬进来、把最终结果写出去一次。

IO 复杂度对比（$N$ 为序列长度，$d$ 为头维度）

标准注意力

$\\Theta(N^2 d)$

整张 $N\\times N$ 分数与概率矩阵都要落在显存里，显存占用 $O(N^2)$。

高

FlashAttention

$\\Theta(N^2 d^2 / M)$

$M$ 是片上内存容量；中间矩阵不落地，显存占用降到 $O(N)$。

低

理想下限

$\\Theta(Nd)$

只读输入、写输出所需的最少搬运量。$d^2/M$ 越小，越接近下限。

下限

条长为示意，非实测比例。

三个实际影响

• 长序列可训练：随 $N$ 线性增长的显存让更长的上下文变得可行。
• 速度提升随块大小与硬件变化，不是固定倍数；大模型长序列上通常更明显。
• 结果精确，但浮点求和顺序改变，与朴素实现不会逐位一致。

反向传播：用重计算换显存

训练时若要存下完整的概率矩阵 $P$，显存又回到 $O(N^2)$。FlashAttention 在反向时用保存的 $(m,\\ell,o)$重新分块算一遍，按需得到 $P$ 的块，再加权求梯度：多付一点算术，换回大块显存。

$\\text{前向存：}Q,K,V,m,\\ell,o\\quad\\text{而非 }P$

什么情况下收益变小

序列很短、块装不满片上内存，或硬件带宽已经很充裕时，分块的开销可能吃掉一部分收益；它与注意力本身的 $O(N^2)$ 算术无关——FlashAttention 并不降低计算量，只降低显存搬运与占用。
