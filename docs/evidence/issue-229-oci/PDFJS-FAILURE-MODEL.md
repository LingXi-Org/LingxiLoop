# Bounded PDF.js server-package trim: failure model before implementation

Scope: the installed `pdfjs-dist@6.3.289` tree in the **server deps stage** only. The SPA build stage retains its own complete root dependency install; `src/components/AttachmentViewer.tsx` imports `pdfjs-dist/build/pdf.worker.min.mjs?url` there. No product source, effective test, published npm package, durable data or deployed image is changed by this draft.

1. **Wrong package/version or stale consumer audit.** The published `ac906946` image's `@lyyzka/lingxios@3.5.6` has one PDF.js runtime consumer: `dist/src/context/document-worker.js` imports `pdfjs-dist/legacy/build/pdf.mjs`, resolves `pdfjs-dist/package.json` and sets CMap, standard-font and WASM paths. The entire published `/app/server`, `/app/src` and `/app/node_modules` code/JSON tree was scanned for `pdfjs-dist`; no second code consumer was found. The trim must abort on a different PDF.js version and keep a contract that rejects new server source imports of removed viewer paths.
2. **PDF worker or dynamic resources missing.** Retain all `legacy/build`, `cmaps`, `standard_fonts`, `wasm`, `iccs`, `image_decoders` and `legacy/image_decoders` content. Verify real PDF text extraction using `e2e/homework/triangle-reference.pdf` with the exact published LingxiOS document-worker against the candidate pruned tree. Also check the package's generic main and legacy module imports.
3. **Browser PDF attachment handling regresses.** Only modify the server deps stage. Do not change the SPA stage, root lock, SPA COPY or dist. The SPA build needs its generic PDF worker URL and continues to receive a full independent install. Compare the SPA Dockerfile stage and run its owning contract.
4. **Licenses, types or diagnostics disappear.** Keep all PDF.js LICENSE files, package.json, `types`, `build/*.mjs`, `legacy/build/*.map` and all resource licenses. The only map removals are the three exact `build/*.mjs.map` files; no published product runtime consumer imports their paired generic build modules, and checked-in production `NODE_OPTIONS` does not enable source maps. Generic build JS remains available. Do not apply a global `*.map` filter or touch maps for the active legacy parser.
5. **Unsafe or misleading measurement.** Validate exact removed relative paths and before/after regular-file hashes of all retained package content. Measure file count, raw bytes and deterministic tar gzip of the package/tree; label these as a package-copy estimate until an actual candidate image is built. Do not claim whole-image savings from this estimate. Keep original npm package contents and exact image as rollback; reverting the Dockerfile/script change restores the former final package.
