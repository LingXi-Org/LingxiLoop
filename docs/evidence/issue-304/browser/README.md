## Ownership fix and integration checkpoint

The product's retained visualization key previously used workspace/session, path and logical instance but omitted `sourceMessageId`. The hook noticed a new source, yet reacquisition returned the old retained owner. The minimal fix adds the source identity to that retained key. Same-owner replays preserve their iframe; a new source performs a new authorized acquisition. A delayed previous-source response never replaces the current card. An old retained iframe may remain parked and hidden for its own original identity; the current card contains exactly one visible owner. No source ID is frozen and no authorization or wire protocol is changed.

Run `01a16238-f8ea-70bd-915a-f76d728fadd3` passed **8/8**, covering generic continuation, approval, pagination/concurrency, real v2 handoff/correction, same/new visualization owner and a deliberately delayed old-owner response.
