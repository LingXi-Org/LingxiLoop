The product consumes public `readRunTrace(identity, operation)` for bounded, explicitly opted-in viewer history enrichment, and explicitly opts its existing authorized SSE route into `streamRun(...,{trace:true})`. Initial streaming setup does not wait for trace. The shared projection defaults to no native trace, and durable IM delivery explicitly keeps it disabled so principal-authorized child trees are never broadcast or persisted. Each native snapshot replaces the metadata tree; null removes native descendants and totals. New root request/fence/lifecycle invalidates old trace clocks. Additional events downgrade aggregate completeness until a current replacement arrives. The runtime already checks current root/each child and frozen audiences; history rechecks required root state after optional enrichment. Cancellation/failure/legacy absent receipts never invent timestamps or zero usage/cost.

`buildNativeRunTrace` translates explicit public span/parent IDs, measured usage and actual execution origin. LLM detail names the inclusion of admission and settlement. Only an exactly matching root tool receipt seq may obtain existing allowlisted product display fields; no raw tool input/output is copied. Children use the native authorized discovery result. Existing UI visual layout is preserved; its footer now distinguishes native execution origin from legacy creation-based data. QueuedAt stays separate. Everything is message metadata, never answer content; removed activity aggregate controls are not restored.
