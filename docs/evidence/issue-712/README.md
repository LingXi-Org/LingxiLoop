# 原生编辑器清理

关联 [问题 712](https://github.com/LingXi-Org/LingxiLoop/issues/712)、[PR 709](https://github.com/LingXi-Org/LingxiLoop/pull/709)。清理前父提交 `5baaaa0e`，包含最新 main 的聊天界面变更。

## 删除与收敛

- 单选、多选字体共用一个控制器；几何字段不再镜像写入 CSS。流式子元素的相对偏移、右侧/底部锚点、居中、内容盒尺寸保留其真实语义，并进入同一版本化操作和撤销链。
- 删除空闲预加载空函数、未使用的前端授权接口、服务端旧编辑器发布/上传/会话/评论/事件入口、智能体整文件写工具、整文件恢复及设计系统安装的旧写入分支。
- 浏览器导出始终进入隔离环境；无界面单测直接调用导出适配器，生产入口没有测试环境分支。
- 删除 162 条被后续相同选择器覆盖的样式声明和 21 个空规则，保留级联顺序。
- 删除无消费者的取证脚本及约 145 MB 开发归档。19 个仍有回归消费者的源码、布局夹具迁至 `scripts/fixtures/native-editors`。生产依赖隔离审计、共享图标叶子分包、正式性能门槛继续保留。
- 内置主题名称与明暗标签中文化；作者文档内容、历史字节和第三方原始资源不改写。

## 保留的正式行为

历史原稿的只读转换、版本资源、租户和项目授权、隔离交互内容、草稿与冲突副本、共享撤销、媒体格式降级、可见区域裁剪、有界缓存、Worker、按需导出，以及部署写入屏障均有实际产品或运行消费者，属于正式能力。新内容只通过原生操作持久化，不保留第二个文件发布入口。本次不新增数据库表。

## 已运行的针对性检查

- 原生编辑器及共享模型：415 项通过；无界面导出：23 项通过；预加载：1 项通过。
- 参考夹具迁移：69 项通过；构建/门槛/退休资源契约：40 项通过；中文文案：3 项通过。
- 系统 Chromium：五项单选字体、八项多选字体（含混合值、锁定、CAS、恢复副本和焦点）、重要声明元素拖动/键盘移动及撤销通过。
- 清理 CSS 前后以相同系统 Chromium 捕获 Design / Slides 的四种容器尺寸、浅深主题及主要菜单，共 41 张截图。39 张 RGB 逐像素相同；两张历史弹窗仅时钟数字不同（Design：`1214,151–1228,160`；Slides：`1187,152–1200,161`），区域外相同。这是清理前后对比，不是上游一比一验收。
- web 与 server lint 均运行。web 保留现有非阻断诊断；本次拥有的文件 lint 无诊断。

本地公开依赖可运行以上检查；私有 SDK 的本地包读取返回 401，因此本地完整类型检查及服务端套件不能据此记为通过。最终候选的 owning web/server/集成检查、独立审查、合并与部署结果在 PR 中记录，未运行项不作通过声明。

首次下载的 Chromium 140 连独立空白页面的普通输入框也无法输入；同一 Playwright 改用系统 Chromium 后输入正常。首次字体检查超时保留为环境失败，不计入产品通过项。一次多选检查使用了不存在的用例名，修正为已有正式用例后重跑；旧代码样式检查把语义标题根误认成链接根，已改为同时验证标题和真实链接。
