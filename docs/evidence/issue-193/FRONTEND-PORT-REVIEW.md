## Remaining gaps versus complete acceptance

1. Copy-image implementation differs materially from native upstream capture; its fidelity and behavior are not yet demonstrated.
2. Browser compatibility is gated by `Element.moveBefore`. The old desktop-only message has been replaced by browser-upgrade wording in both locales. This remains a capability gate, not universal Web support.
3. External opening now handles a null popup result and failed authorization in source. Browser user-activation timing, navigation success and rejection propagation must still be tested; the source fix does not itself prove cross-browser popup behavior.
4. State synchronization now has explicit revision and invalidation handling, but its 10-second remote fallback differs from desktop native notifications. Its correctness and lifecycle integrations need execution evidence.
5. Source-mode fixture sharing a host/CSS proves only the source differences that are independent of those shared parts. Full original CSS baseline, host security tests and native screenshot/capture comparison are distinct gates.

No omission was found in the transplanted toolbar, Dialog, grouped parameters, reset/original preview or variant source paths. That is a source conclusion, not an interaction pass. The source review changes no active code and does not mark the issue complete.
