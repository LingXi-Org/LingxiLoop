# Final image source correspondence — failure model

Written before implementation. Only local files and local Git objects are read. The frozen OCI auditor is not imported or changed; no registry, Docker, product tests, database, provider or production call is made.

- Require a successful OCI receipt, exact expected 40-hex commit, matching inventory SHA256, expected repository, and valid immutable index/manifest/config digests. A successful source check is conditional on the independently verified OCI receipt, not an independent signature/provenance verification.
- Freeze the reviewed final Docker COPY and dockerignore policy. If either Git blob changes, fail closed until the narrow copy policy is reviewed again. Map every expected directly copied tracked file; do not infer that the entire frontend source should exist in the runtime image. Root app/package.json and package-lock.json map to server equivalents.
- Missing expected source, extra unknown non-generated paths, wrong kind/length/hash, or missing/incorrect 48 sequential migrations/Web/Worker/migration entry/participantDisplayName all fail. Symlink blobs compare their link-text hash; regular/hardlinked file bytes compare content SHA256. Direct-copy subtrees must not silently accept unknown files or missing members.
- Only untracked app/server/assets/visualize-runtime/** is classified generated/uncompared. Generated files are listed, never called Git-matched. Dist, dependency, base-OS files are explicitly outside this source-only scope and remain covered by their other gates.
- Read Git using argument arrays, exact commit and batched cat-file requests. Disable replace refs/global config for correspondence reads; do not fetch or alter worktrees. Stream each blob into SHA256; never write or print its body or config/Env/credentials.
- Input limits, new output directory and finite timeout prevent accidental overwrites/unbounded local processing. Failure output uses fixed error codes, paths/counts/hashes only, not subprocess stderr or raw exceptions.
- Synthetic local Git tests must include wrong commit, bad inventory hash, missing source, altered bytes and unexpected path. No actual image exists yet; fixtures cannot establish OCI readiness, isolation or deployment.
